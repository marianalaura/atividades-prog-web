# Memória de Código

Jogo da memória com tema de tags e comandos de programação. O objetivo é achar os 8 pares escondidos entre as 16 cartas, no menor número de movimentos possível.

## Objetivo do jogo

Achar os pares de símbolos de programação (`<html>`, `<div>`, `{ }`, `( )`, `=>`, `const`, `git`, `npm`) virando duas cartas por vez. Se as duas cartas forem iguais, elas ficam viradas. Se forem diferentes, voltam para baixo. O jogo acaba quando todos os pares são encontrados.

## Regras do jogo

1. Clique em "Começar" para embaralhar as cartas.
2. Clique em uma carta para virá-la.
3. Clique em outra carta:
   - se os símbolos forem iguais, as duas ficam viradas;
   - se forem diferentes, as duas voltam para baixo depois de um tempo.
4. Cada duas cartas viradas contam como um movimento.
5. O jogo termina quando todos os 8 pares forem encontrados.
6. Dá pra reiniciar a qualquer momento no botão "Reiniciar".

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript (sem bibliotecas ou frameworks)
